An app for anyone that works in the electrical field/industry to use. You type in a question or statement or equation and it will give you code references per the NEC NFPA 70 as well as cross reference with NECA and OSHA. It should be able to calculate for footages, voltage drops, resistance, Conduit bending, temperature, Amperage, power, efficiency, and any other calculations that would be needed in any position in the electrical industry/field or similar type of work.
